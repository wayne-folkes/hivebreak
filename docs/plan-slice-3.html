Hivebreak slice 3

A soundtrack that reacts to play, and a reason to come back: milestones that unlock ships, Specials and upgrades.

Two releases, each deployed and played before the next. 3a adds the music. 3b adds the unlocks. Everything stays in the browser: no backend, no cost. The pictures are concept renders drawn live with Three.js at the game's 180 × 320 resolution; the shapes are stand-ins for the Blender models.

Release 3a: the soundtrack across a run

Four tracks synthesized in code, like the sound effects: square and triangle voices and a noise drum, written as note patterns. Layers fade in as a wave thins and when you're on your last life; the boss theme shifts gear at each phase.

Done means

3a

  • Title, both sectors and the bosses have their music; stingers on wave clear, pick, victory and game over.
  • Layers build as waves thin and on the last life; bosses shift gear by phase.
  • Ducks under big moments, slows under Time Stop and Slow.
  • Its own on/off and volume; no glitches on pause, tab away or restart.

3b

  • New players start with the trimmed pool.
  • Each milestone unlocks what it says, once, with an unlock moment.
  • The unlocks screen shows progress and what's next.
  • Ships and the new Specials play as designed; progress survives reloads and can be exported.

Steps

As in slices 1 and 2: I write each release's contract, smaller models build in parallel on separate files, the reviewer checks every round, and I play-test before pushing. Blue numbers run as parallel workers.

  1. 3a contract main session

    The song format (tempo, channels, note patterns, layers, loops) and the music API (play, stinger, intensity, boss phase, duck, time scale, volume).

  2. 3a engine, tracks, settings 3 in parallel

    • Sonnet sequencer on Web Audio, scheduled ahead so it stays in time; crossfades, layers, ducking, time scaling, stingers on the beat.
    • Sonnet composer: the four tracks and stingers as data, with a dev page to audition them.
    • Haiku music on/off and volume in Settings.

  3. 3a wiring, review, ship

    A music director in main.ts picks tracks by screen and wave and feeds intensity, boss phase, ducking and time effects. Play-tested by ear on desktop and phone.

  4. 3b contract main session

    Unlock ids, milestone definitions, the versioned progress save, ship definitions, and the new Specials and upgrades in the existing unions.

  5. 3b logic and models 3 in parallel

    • Sonnet progression: milestone checks, unlock bookkeeping, starting pool, save, export and import.
    • Sonnet new content: ships, Missile Swarm, Gravity Well, four upgrades and two synergies, only unlocked items offered.
    • Sonnet Blender models: Interceptor, Lancer, Bulwark, missile, Gravity Well core.

  6. 3b renderer, UI, sound 3 in parallel

    • Sonnet renderer: ships, missiles, the well's pull.
    • Sonnet UI: ship choice, unlocks screen, the unlock moment, export and import.
    • Haiku sound: unlock fanfare, the new Specials.

  7. 3b wiring, review, ship

    As for 3a.
